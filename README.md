# asobi

わくの遊び用ページ置き場(GitHub Pages)。

- `yomiage/` … 悪ノリ読み上げ:文を打って、声の高さ・速さ・連呼をいじって喋らせる
- `loop/` … クセループ:16ステップのドラムとメロディ、自分の声を録音して混ぜるループメーカー
- `idou/` … 移動時間マップ:車と電車の所要時間を地図で色分け。「県ごと」は47都道府県の県庁所在地どうし(県をタップすると時間と電車のルート)、「細かく」は約4.5kmのマス目で、地図のどこをタップしてもそこからの時間をその場で計算する(▶で行ける範囲が広がる様子を再生)

どれもスマホのSafariで開いて「ホーム画面に追加」できる。保存したボタンやパターン、録音した声はその端末の中だけに残る。

移動時間マップのデータ:
- 県ごと:車は OpenStreetMap の道路データ(© OpenStreetMap contributors)から OSRM でルート計算(高速あり・渋滞なし)、電車は新幹線・特急の代表的な所要時間で作った路線モデルからの推定(乗り換え1回につき12分)
- 細かく(`idou/mesh.json`):道路は Natural Earth の高速道路・幹線道路+マス目の地元の道(速度は県庁所在地間のOSRMの時間に合わせて調整)、鉄道は国土交通省「国土数値情報(鉄道データ)」2024年を加工+上の新幹線・特急。計算はブラウザの中でダイクストラ法
