# asobi

わくの遊び用ページ置き場(GitHub Pages)。

- `yomiage/` … 悪ノリ読み上げ:文を打って、声の高さ・速さ・連呼をいじって喋らせる
- `loop/` … クセループ:16ステップのドラムとメロディ、自分の声を録音して混ぜるループメーカー
- `idou/` … 移動時間マップ:47都道府県の県庁所在地どうしの、車と電車の所要時間を地図で色分け。出発地を選んで県をタップすると時間と電車のルートが出る

どれもスマホのSafariで開いて「ホーム画面に追加」できる。保存したボタンやパターン、録音した声はその端末の中だけに残る。

移動時間マップのデータ:車は OpenStreetMap の道路データから OSRM でルート計算(高速あり・渋滞なし)、電車は新幹線・特急の代表的な所要時間で作った路線モデルからの推定(乗り換え1回につき12分)。
